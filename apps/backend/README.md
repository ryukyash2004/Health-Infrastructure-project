# Archive: Development & Debugging Utilities

This directory contains stray files and scripts used during the initial setup and MVP development of the Aegis backend.

## Files Archived:

- **check_imports.py**: A script used to verify that essential library imports (like FastAPI and Pydantic) were correctly resolved within the environment.
- **GEMINI.md**: A project-specific instruction file containing backend-specific coding rules and architectural guidelines used by the AI assistant during development.
